Delete account

Cloud accounts are optional and free. If you created one, you can delete it and every cloud build from the builder.

Delete a cloud account

Sign in to the builder, open Cloud builds under My build library, and choose Delete account. The account deletion runs the delete_own_account() database function, which deletes only the signed-in user's auth row; the builds table cascades and removes that user's cloud builds.

If you cannot sign in, use the password reset on the sign-in form. If you still cannot access the account, use the project issue tracker linked from the project page and include the account email; never send your password.

Clear local data

Builds, preferences and the local library are stored in this browser. Clear this site's storage in your browser settings to remove them. Export any builds you want to keep first.

What is deleted

Cloud deletion removes the account email, build names, build codes and timestamps from Supabase. Local browser data is separate and is removed only when you clear site storage.
