# Browser comparison: Free Builder and Goated Build Lab

Tested 2026-11-01 in desktop Chromium and at a 390-pixel viewport. The reference was signed out. This is a representative workflow audit, not a test of every input, every possible build, camera output, account, paid feature, or server function.

| Area | Browser observations |
| --- | --- |
| Finder | The Floor general preset produced 12 results on each site. Both placed the same PG 6'3", 170 lb, 6'9" wingspan PlayShot Point first and showed the same 21 base attributes. The reference took 1.8 s and Free Builder 1.7 s in this single run; this is not a performance benchmark. |
| Builder / 99 wall | The matched reference result displayed 99, raw 98.9998. Initially Free Builder displayed 96 in the finder, then changed ratings and displayed 98 in the builder. Its code used position instead of the engine's height bucket for overall, and inches instead of that bucket for linked attributes. After correction and cache refresh, the same build retained its attributes and displayed 99, true 98.9. An attempt to raise Pass Accuracy from 97 to 99 was limited to 97. |
| Cap breakers | With five breakers and Driving Dunk, both listed 45 frames and PG 5'9" 28 → 77 (+49) first. Three-Point also listed 45; the first three were C 7'2", 7'3", and 7'4", each 59 → 89 (+30). On Free Builder, the first Driving Dunk row correctly prefilled PG, 5'9", five breakers, and 77 in the finder; that search returned seven builds. The reference's row-to-build action is paid. |
| Badge search | Searching Limitless Range returned one result on each. Free Builder showed Bronze 83, Silver 89, Gold 93 and HOF 99; the reference showed the same badge's mechanics and a detailed badge page. The search/requirements example is not a complete badge audit. |
| Takeovers | Free Builder listed Inside Touch with Close Shot 85, Detonator with Standing Dunk 85, and Airspace with Driving Dunk 87 plus Vertical 75, matching the reference entries inspected. The reference provides deeper effect details. |
| Motion styles | At 6'6", both showed 232 styles and recommended Drew Eubanks at 4.87 s. At 6'2", both showed 114 fitting styles and recommended Markelle Fultz at 4.76 s, with matching four measured runs. |
| Animations | Free Builder searched Stephen Curry and returned 35 matches from 2,494 entries. The reference's complete standalone list is Premium, so the lists could not be compared end to end. |
| Archetypes | Searching PlayShot Point returned one name on each. The reference said 1 of 3,713 names and Free Builder 1 of 3,721 source rows; the denominator difference is unresolved. |
| Build collections | The reference and Free Builder displayed the same 18 GOAT names and 11 GOATED player names in the inspected lists. Free Builder offers a fitted version for cards that are illegal in its normal builder; this is not a full comparison of the reference's special-card editor. |
| Local library | A temporary named Free Builder build was saved, loaded and deleted successfully. Cloud synchronization and accounts were not tested. |
| Solvers | Optimize ran locally; the reference showed a Mid gate. Min-max and badge-building originally advertised 12 results for the sample, but the first offered result was rejected by the builder as over budget. Results are now checked before being offered; min-max additionally checks retained badge tiers and a gain. A badge search whose finder row exceeds the wall is fitted down while keeping the requested badge floors, instead of showing zero usable results. Threshold chips, Must-reach and cap-breaker writes now use the same validated edit path as the sliders, so none of them can bypass the 99 wall. A lack of verified results does not prove no valid build exists. Paid reference results could not be tested. |
| Upgrade Planner | Reference accepted 100,000 VC on its default SG 6'6" example and estimated 60.04 → 76.02 overall. Free Builder now has a local planner built from the recovered VC ladder and badge-threshold functions: the same default body starts at 60.00, and 100,000 VC estimates 76.00. Its badge plan lists each purchase, running total, overall, and the cap each remaining badge needs. These are the game's arithmetic, not independently verified in-game prices. |
| Jumpshots | Reference's free-throw example displayed a 73 ms green window at rating 75. Free Builder's 3D Jumpshot Lab originally rendered a shell but failed to initialize its timing data on a non-reference origin. The origin-locked data key has been replaced with the local development key, so the 3D trainer now mounts on the published origin; the free-throw example was rechecked at 73 ms locally. The separate Practice Lab still labels its numbers as estimates. |
| Face scan | Reference exposes name/photo-to-head and fine-tuning controls. Free Builder's beta now accepts an uploaded photo or camera frame, runs the 478-point MediaPipe landmarker, overlays the points, and keeps/downloads a local measurement profile. A supplied portrait detected 478 landmarks and 52 blendshape channels. The reference's photo-to-head mesh generation and fine-tuning remain a different pipeline and were not reproduced. |
| Mobile | At a simulated 390 px CSS viewport, neither homepage had document-level horizontal overflow. This does not establish full mobile usability. |

The reference displayed sign-in and subscription gates, and reported that new subscriptions were closed. Premium solver outcomes, paid-account behavior, cloud and community features, league uploads, camera output, accessibility audits, every animation or badge, and every search combination remain unverified. Online Community is not a priority for this project. One local Practice Lab test rep was recorded in the browser profile.
