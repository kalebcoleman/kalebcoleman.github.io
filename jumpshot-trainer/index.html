    Free practice

    Build a repeatable release

    One rep is a short, local timing exercise. The target moves slightly from shot to shot, so the goal is a repeatable release rather than memorising one number.

    Run a rep

    1. Choose a setup below or keep the saved one.
    2. Start the shot, then release when the cue flashes, the audio cue sounds, or the marker reaches the green band.
    3. Read the local error and the suggested next focus.
    4. Repeat or run a free-throw set to change tempo.

    Controls

    Space
    Start a rep when idle and release when armed, while the timing bay is in view or the shot pad has focus.
    S
    Start a rep from anywhere outside a form field; the timing bay scrolls into view.
    Esc
    Cancel an armed shot without logging it.
    Tab / Shift+Tab
    Reach every control, including the shot pad.

      What this trainer does and does not do

      What it does

      • Times your browser input against an estimated local release target.
      • Stores settings, calibration offset and practice attempts on this device.
      • Summarises your release bias, spread and clean-release rate.
      • Suggests practice adjustments and drills from that local log.

      What it does not do

      • Read, measure or reproduce NBA 2K shot timing or tuning tables.
      • Connect to a game, console, account or server.
      • Predict in-game makes or replace in-game practice.
      • Upload your settings or attempts anywhere.
